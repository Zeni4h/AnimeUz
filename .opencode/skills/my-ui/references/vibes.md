# Vibes (AnimeUz)

Content/discovery site: catalog grids, search, detail pages, trailers, ratings.

Defaults:
- Library: shadcn + existing dark violet theme
- Density: comfortable, cards 12px radius
- Motion: calm steady, no hover lifts
- Graphics: real AniList/TMDB art as files/remote, never generated logos. Empty states: one line + calm art + next action (e.g. "Try another search").
- Mobile: grid -> 2-col, filters in sheet, 44px targets.
